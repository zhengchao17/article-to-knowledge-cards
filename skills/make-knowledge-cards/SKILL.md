# Make Knowledge Cards

## Overview

将文章或本地 Markdown/TXT 文件的核心知识提取为 5~8 张结构化知识卡片，每张卡片聚焦一个知识点，包含标题、核心知识、简明解释和例子或自测问题。

## Workflow

### 1. 获取源内容

按优先级获取用户输入的内容：

1. **直接粘贴**：用户在消息中粘贴的文章文本 → 直接使用
2. **本地文件**：用户提供文件路径（仅 `.md` / `.txt`）→ 用 Read 工具读取内容

如果用户未提供任何内容，提示用户粘贴文本或提供文件路径。

**拒绝的情况**：
- 网页 URL → 告知暂不支持网页抓取，请用户粘贴正文
- PDF 文件 → 告知暂不支持 PDF，请用户粘贴正文或转换为 TXT
- 其他二进制格式 → 同上

### 2. 分析与提取

通读全文后执行以下步骤：

1. **识别核心知识**：找出文章真正重要的知识点，忽略过渡句、重复论述和装饰性文字
2. **去重**：合并表达相同或高度重叠的知识点，确保每张卡片讲的是不同内容
3. **量化**：提取 5~8 张卡片。如果文章信息量不足以支撑 5 张，按实际提取，不强行凑数，并在输出末尾注明"本文信息量有限，共提取 N 张卡片"
4. **忠实原则**：所有知识点必须来自原文，不得编造原文没有的信息
5. **短文处理**：对于 300 字以内的短文，不要为了凑够 5 张而拆分过细，每个卡片应保持知识完整性

### 3. 生成知识卡片

每张卡片严格包含以下四个字段：

| 字段 | 说明 |
|------|------|
| **标题** | 10 字以内，概括该知识点 |
| **核心知识** | 一句话陈述核心事实或结论（≤ 40 字） |
| **简明解释** | 2~4 句话展开说明，通俗易懂 |
| **例子 / 自测问题** | 提供一个具体例子加深理解，或一个自测问题帮助回忆 |

#### 卡片格式

使用 Markdown 格式输出，每张卡片之间用 `---` 分隔：

```markdown
### 📌 [标题]

**核心知识**：[一句话核心陈述]

**解释**：[2~4 句展开说明]

**💡 例子 / 自测**：[具体例子或自测问题]
```

### 4. 输出与保存

1. 在对话中直接输出所有卡片，开头注明卡片总数（如"共 6 张知识卡片"）
2. 询问用户是否需要保存为文件。如需保存，默认输出为 Markdown 文件到用户指定路径或当前工作目录
3. 保存文件时，文件名建议格式：`knowledge-cards-[原文主题].md`

## Quality Checklist

生成卡片前，逐条检查：

- [ ] 每张卡片只讲一个知识点
- [ ] 标题简短、有区分度
- [ ] 核心知识是一句话、不超过 40 字
- [ ] 解释通俗，不照搬原文长句
- [ ] 例子/自测与知识点直接相关
- [ ] 无重复卡片
- [ ] 无原文以外的编造信息
- [ ] 卡片数量 5~8（信息不足时按实际提取）
